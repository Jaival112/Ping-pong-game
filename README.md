# Ping-pong-game
Gameplay

- Two players control paddles on either side of the screen.
- The ball moves automatically and bounces off the top and bottom edges.
- When the ball passes a paddle, the opposing player scores a point.
- The current score is displayed at the top of the screen.

Controls

Left Player (Red Paddle)**  
- `W` → Move Up  
- `S` → Move Down

Right Player (Blue Paddle)**  
- `↑` (Up Arrow) → Move Up  
- `↓` (Down Arrow) → Move Down
   Features
- Smooth paddle movement with keyboard input
- Real-time score tracking
- Ball and paddle collision detection
- Dynamic ball motion
